# Laboratorios

El curso contiene seis laboratorios, organizados de manera uniforme:

- [Lab 0](Lab0/) — Matriz exportadora boliviana, 2000–2024.
- [Lab 1](Lab1/) — Prueba ricardiana con productividades sectoriales.
- [Lab 2](Lab2/) — Contraste empírico de Heckscher–Ohlin.
- [Lab 3](Lab3/) — Modelo de gravedad estructural.
- [Lab 4](Lab4/) — Incidencia de aranceles mediante un diseño *shift-share*.
- [Lab 5](Lab5/) — Descomposición del comercio en valor agregado.

Cada laboratorio incluye:

- `datos/`: bases y diccionarios de variables;
- `codigo/`: archivos reproducibles;
- `plantillas/`: formatos de trabajo e informe; y
- `informe/`: informes y productos finales del laboratorio.
